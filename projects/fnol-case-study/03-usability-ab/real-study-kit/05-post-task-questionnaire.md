# Post-task questionnaire

Ask these questions aloud, or hand them over on paper. Write the answer on the note grid. Record the number exactly as the participant gives it.

## Part A: after each task (ask after task 1, then after task 2)

1. Overall, how easy or difficult was it to report your claim? 1 = very difficult, 7 = very easy. **(SEQ, 1 to 7)**
2. How satisfied are you with the chat? 1 = very dissatisfied, 5 = very satisfied. **(CSAT, 1 to 5)**
3. What stood out? In one or two sentences, in your own words. **(comment)**

## Part B: after both tasks

1. Which chat would you rather use if this happened to you, and why?
2. Was there a moment either chat felt slow or repetitive?
3. Did either chat miss or get something wrong?

## Scoring notes

- SEQ and CSAT are single items. Keep the scale exactly as written, and do not show a longer list.
- Read the question as written. If the participant asks what a number means, repeat the scale. Do not explain the chat.
- Write the comment in the participant's words. Do not tidy it up.
- Code the comment later (see `06-analysis-plan.md`). Do not code during the session.
- Part B question 1 is the preference. Record "chat 1" or "chat 2" as the participant names it, and map it to the variant from the session command afterwards.
- If the participant gives no number, leave the cell blank and write "no answer" in the moderator notes.

# Moderator script (50 minutes)

Read the lines in quotes aloud, as written. Everything else is a note for you.

| Block | Minutes | Running total |
|---|---|---|
| Welcome and consent check | 5 | 5 |
| Think-aloud practice | 3 | 8 |
| Task 1 | 10 | 18 |
| Post-task questionnaire (task 1) | 3 | 21 |
| Task 2 | 10 | 31 |
| Post-task questionnaire (task 2) | 3 | 34 |
| Preference interview | 8 | 42 |
| Debrief | 3 | 45 |
| Buffer (overruns, questions) | 5 | 50 |

## 1. Welcome and consent check (5 min)

"Thanks for coming in. This is a study about how people report a car insurance claim to a chat assistant. The assistant is called Sam. Sam is fictional, and so is the insurer. We are testing the chat, not you. There are no wrong answers."

"Before we start, can I check you have read the information sheet and that you are happy to go ahead?"

"You can stop at any time, and you keep the gift card if you do. Is it OK if I record the screen and audio?" *(Only if the recording box is ticked. If not, say: "I will take notes only.")*

Check the signed consent form is complete. Note the time.

## 2. Think-aloud practice (3 min)

"I'd like you to say out loud what you are thinking as you go. Even if it feels unimportant. For practice, please tell me what you think of this page." *(Show a plain web page or the terminal with the blank prompt.)*

"What are you thinking?"

## 3. Task 1 (10 min)

Hand over the card for Task 1. Check the variant and card from `04-task-cards.md`.

"Here is a card with a made-up scenario. Please use the details on the card, and chat with Sam as you would if this had really happened to you. Tell me when you are finished, or type quit."

Let the participant read the card first. Start the command only when they say they are ready.

Start the session with the command from `04-task-cards.md`. Type the command before the participant looks at the screen. The screen clears when the chat starts. After the session, check the file name in `results/real/session_log.txt`, not on screen. Then step back.

Stop the task at 10 minutes, even if the chat is not finished. Say: "Thanks. We will stop here for this chat." Use a timer. At 10 minutes, type `quit` for the participant if they have not finished. Note 'stopped at 10 min' in the grid.

## 4. Post-task questionnaire, task 1 (3 min)

Use `05-post-task-questionnaire.md`, questions 1 to 3, for task 1.

## 5. Task 2 (10 min)

"Now here is a second card. The steps are the same, and it is a different scenario."

Hand over the card for Task 2. Let the participant read the card first. Start the command only when they say they are ready.

Start the second session with the second command from `04-task-cards.md`. Type the command before the participant looks at the screen. The screen clears when the chat starts. After the session, check the file name in `results/real/session_log.txt`, not on screen.

Stop at 10 minutes, as before. Use a timer. At 10 minutes, type `quit` for the participant if they have not finished. Note 'stopped at 10 min' in the grid.

## 6. Post-task questionnaire, task 2 (3 min)

Use `05-post-task-questionnaire.md`, questions 1 to 3, for task 2.

## 7. Preference interview (8 min)

"Thinking about both chats, which one would you rather use if this happened to you, and why?"

Use the three follow-up questions in `05-post-task-questionnaire.md` (part B). Keep to neutral prompts. Do not name the chats by variant. Say "the first chat" and "the second chat" if you need to.

## 8. Debrief (3 min)

"Thank you. Is there anything you would like to add that we have not asked?"

"We will send you a receipt for the gift card within [timeframe, to be set by the study team]. If you have questions later, here is my contact."

Stop the recording. Save the session files.

## Neutral prompts

Use these when the participant goes quiet or asks what to do. Do not add to them.

- "What are you thinking right now?"
- "What would you do next?"
- "What did you expect to happen there?"
- "Can you tell me more about that?"
- "What is making you pause?"

## Do not

- Do not give hints or tell them what to type.
- Do not name the variants, and do not say "story-first" or "form-first" in the room.
- Do not say whether Sam is doing well or badly.
- Do not correct Sam's answers or the participant's wording.
- Do not fill silences for more than a few seconds. Use a neutral prompt instead.
- Do not talk about the other variant while a task is running.

## If Sam fails

Sam may misunderstand, lose track or make a mistake. That is data.

1. Let the participant decide what to do next. Do not rescue them.
2. Note the time, the message, and what the participant said. Use the grid below.
3. If the participant asks for a person, the chat may pass to a person. Note it. The session ends there.
4. If Sam asks for a date of birth or another detail that is not on the card, say: "Use the policy number on the card. That is enough. If Sam needs more, make up a plausible answer." Note it in the grid.

## Distress protocol

Participants can feel upset, especially if a chat is about a crash.

1. Pause the session. Say: "Let's take a moment."
2. Ask: "How are you feeling right now? Would you like a break, or would you like to stop?"
3. If the participant wants to stop, end the session. Say: "Thank you. You keep the gift card."
4. Offer support. Lifeline is 13 11 14 (24 hours a day, Australia). Say the number aloud.
5. Note what happened in the grid. Tell the study lead the same day. Do not continue the session unless the participant asks to.
